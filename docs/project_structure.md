# Project Structure

The project is divided into two primary directories: `backend` and `frontend`.

## `backend/`

The backend utilizes FastAPI and follows a Domain-Driven Design (DDD) layout to maintain modularity.

```text
backend/
├── alembic/                  # Database migration scripts (generated by Alembic)
├── app/
│   ├── config/               # Pydantic Settings and Environment configurations
│   ├── database/             # Async SQLAlchemy Engine & Session setups
│   ├── domains/              # Core business logic divided by domains
│   │   ├── hcp/              # HCP (Healthcare Professional) specific routes & models
│   │   └── interaction/      # Interactions specific routes, logic, and AI integration
│   ├── exceptions/           # Custom API exceptions and global error handlers
│   ├── middleware/           # FastAPI middlewares (e.g., CORS setup)
│   ├── models/               # SQLAlchemy Base declarative classes
│   ├── schemas/              # Pydantic Base schemas shared across domains
│   ├── services/             # External services (e.g., Groq LLM Client setup)
│   └── main.py               # Application entrypoint & FastAPI instance creation
├── alembic.ini               # Alembic configuration file
├── Dockerfile                # Instructions to containerize the backend
├── docker-compose.yml        # Local development compose file
├── pyproject.toml            # Project dependencies and tool configurations
└── uv.lock                   # Lockfile generated by `uv`
```

### Key Backend Components

* **`app/domains/interaction/service.py`**: Contains the critical `chat_with_ai` method which interfaces with Groq, parses the JSON payload, and mutates the database draft.
* **`app/database/session.py`**: Initializes the `asyncpg` engine to communicate with Neon in an async, non-blocking manner.

## `frontend/`

The frontend is a React Single Page Application generated via Vite.

```text
frontend/
├── public/                   # Static assets (favicons, etc.)
├── src/
│   ├── app/                  # Redux Toolkit store initialization
│   ├── components/           # Reusable React components
│   │   ├── chat/             # Chat UI and message bubble components
│   │   ├── forms/            # Form inputs and interaction read-only forms
│   │   ├── layout/           # Global wrappers, Sidebar, Topbars
│   │   └── ui/               # Generic UI primitives (Buttons, Inputs, Spinners)
│   ├── features/             # Redux slices grouped by feature
│   │   └── interaction/      # Global state for drafts and chat sync
│   ├── hooks/                # Custom React Hooks (e.g., useDraftAutosave)
│   ├── pages/                # Top-level route components
│   │   ├── HCPHistoryPage.tsx    # HCP historical timeline view
│   │   ├── InteractionHomePage.tsx # Dashboard with drafts & saved HCPs
│   │   └── LogInteraction/       # AI interaction logging interface
│   ├── services/             # External service wrappers
│   │   └── api/              # Axios instances and API endpoint definitions
│   ├── App.tsx               # Main React component and Routing map
│   └── main.tsx              # React DOM mounting entrypoint
├── index.html                # Vite HTML template
├── package.json              # NPM dependencies and scripts
├── tailwind.config.js        # Tailwind CSS styling configuration
├── tsconfig.json             # TypeScript compiler rules
└── vite.config.ts            # Vite bundler configuration
```

### Key Frontend Components

* **`src/services/api/axios.ts`**: The central Axios instance configured with the `VITE_API_URL` environment variable.
* **`src/pages/LogInteraction/index.tsx`**: The main interface that marries the form UI and the chat UI together for the interaction logging process.
